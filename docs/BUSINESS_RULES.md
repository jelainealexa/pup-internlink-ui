These are design recommendations, not institutional ERD assertions: validate trimmed inputs; reject nonfinite/negative required hours; keep ID foreign keys consistent; write related records atomically; record authenticated actor/time where reviews/decisions require attribution; maintain explicit schema version and fail visibly on storage errors; enforce idempotency/conflicts; separate synthetic storage from API mode; derive totals from one approved counting policy.
