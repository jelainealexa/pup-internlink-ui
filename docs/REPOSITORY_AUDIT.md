## Data and calculation findings

Shared fixtures are an improvement over repeated per-page maps but are not normalized or writable. No fetch, localStorage, sessionStorage, IndexedDB, server actions, database calls or route handlers implement mutations. Student/program/placement summaries repeat values; changes in one component do not reach another.

Angela's visible reports sum to 115 hours versus placement total 320; Miguel's sum is 75 versus 280; Sofia has no reports but 486 hours. An undocumented historical opening balance could explain these, but none is modeled. Miguel reports dated October precede his November placement start. app-003 references Maya/Junior Data Analyst absent from company/opportunity fixtures. Nicole's accepted IBM application uses Computer Science while the IBM opportunity's local eligibility list excludes that program. This is fixture inconsistency, not evidence that a specific approved eligibility rule exists.

Progress arithmetic matches rendered/required for current positive fixtures; remaining hours are clamped at zero in several views. Most ratios lack zero/negative guards. Required-hours input has no positive bound; invalid values would corrupt ratios if future writes reused this code. Dashboard ratio and evaluation totals are illustrative, not calculations from current records. Certificates are fabricated display strings, not issued artifacts.
