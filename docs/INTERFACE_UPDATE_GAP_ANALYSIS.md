## Reversible reconciliation policies

- Keep internal Coordinator ID value for saved-data compatibility and label it OJT Coordinator. Legacy Company Supervisor accounts become Intern Supervisor with same profile/placement/evaluator IDs; never grant legacy accounts administrative rights. Fresh demo seed supplies separate explicit company administrators.
- Faculty pre-registration automatically assigns the new student to that faculty member; existing edits/invitations/deactivation restricted to assigned scope. Coordinator may assign before placement. Block reassignment conflicting with an ongoing placement; historical placement/evaluation assignments remain frozen.
- Coordinator retains documented oversight application decision authority from the old specification, using the same one-way decision record as assigned Intern Supervisors. No independent statuses or automatic placement.
- Pending Company -> Pending Coordinator -> Approved -> Active; Filled is derived from exhausted capacity; Deactivated retains history. Company and coordinator decisions recorded separately. Material edit resets approval. Legacy approved postings remain available through an explicit grandfathered migration, not forged new company approvals.
- Only Before mandatory documents gate initial application acceptance/placement. Freeze all currently mandatory phase IDs at placement creation for completion; added later requirements do not retroactively invalidate historical completion.
- Legacy reviewed hours are grandfathered as approved with provenance. New approvals/rejections belong to assigned Intern Supervisors; faculty adds separate immutable monitoring remarks. Attendance supplies rendered hours and linked weekly report hours; each attendance entry contributes once, never again through both attendance and weekly aggregation. Legacy daily report work dates cannot overlap new attendance.
- Deactivation of an Intern with ongoing assignments is blocked until reassignment/resolution. Pending evaluation obligation can follow an audited reassignment; a submitted company evaluation freezes that assignment until the placement closes. No third evaluation.
- Activation requires a bound local invitation plus matching number/email; pending activation differs from deactivation. Local reset requests expire and are single-use; current-credential changes invalidate prior sessions. No plaintext passwords or real email delivery.
